# Risk-Management-Awareness-Day-Project

A project that reflects our commitment to raising security awareness among everyone, starting with raising and strengthening security awareness among non-experts in the field of cybersecurity, and ending with reminding experts of the importance of this awareness.

We as a university group picked "Policies, guidelines and standards in cybersecurity" topic as our project idea to present it in the Gutech Awareness Day Exhibition. This project incorporates several elements from our Risk Management course, taught by Mr. Raga Anwar at Gutech University in Oman.

One of the main things we did is building a challenges/quizzes website that tests everyone knowledge in this topic. You can try this website going to "Deployments" section and clicking "github-pages" where the link of the website is there. It's fully-frontend website, so no need to register/login user (:
