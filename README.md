# CyberShield — Policies, Guidelines & Standards
An interactive cybersecurity awareness and risk management learning platform designed for the GUtech Cybersecurity Awareness Exhibition 2026.

# Overview
CyberShield is a fully interactive, single-page web application developed as part of a Risk Management course project. This project reflects our commitment to raising security awareness among everyone, starting with raising and strengthening security awareness among non-experts in the field of cybersecurity, and ending with reminding experts of the importance of this awareness.

The project focuses on helping users understand the differences between cybersecurity Policies, Guidelines, and Standards, while also introducing industry-recognized frameworks such as ISO 27001, NIST, CIS Controls, and other governance and compliance concepts.

Rather than presenting information as static content, CyberShield uses interactive educational modules that allow users to learn by doing, making cybersecurity awareness more engaging and memorable.
